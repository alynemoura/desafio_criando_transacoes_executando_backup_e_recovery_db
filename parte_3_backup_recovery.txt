-------------------SCRIPT COMPLETO CRIANDO TRANSAÇÕES, EXECUTANDO BACKUP E RECOVERY DE BANCO DE DADOS PARTE 3-----------------------

1- Usando o PowerShell: verificar se o MySQL está no PATH do Windows:
mysql --version
mysqsldump --version

2- Criando o diretório para armazenar os backups
New-Item -ItemType Directory -Force -Path "C:\Backups\ecommerce" 
Set-Location "C:\Backups\ecommerce"

3 - Backup completo do banco de dados Ecommerce(estrutura + dados)
mysqldump -u root -p `
  --databases ecommerce `
  --routines `
  --events `
  --triggers `
  --single-transaction `
  --set-gtid-purged=OFF `
  --result-file="C:\Backups\ecommerce\ecommerce_full_backup.sql"


4- Backup sem dados (apenas estrutural)
mysqldump -u root -p `
  --databases ecommerce `
  --no-data `
  --routines `
  --events `
  --triggers `
  --result-file="C:\Backups\ecommerce\ecommerce_schema_only.sql"
  
5- Backup sem estrutura (apenas os dados)
mysqldump -u root -p `
  --databases ecommerce `
  --no-create-info `
  --skip-triggers `
  --result-file="C:\Backups\ecommerce\ecommerce_data_only.sql"
  
6- Verificando quais bancos existem no sistema:
mysql -u root -p -e "SHOW DATABASES"


7-Backup de múltiplos bancos de dados
mysqldump -u root -p `
  --databases ecommerce sakila world `
  --routines `
  --events `
  --triggers `
  --single-transaction `
  --result-file="C:\Backups\ecommerce\multiplos_bancos_backup.sql"
  
8-Backup com rotinas
mysqldump -u root -p `
  --databases ecommerce `
  --no-data `
  --routines `
  --events `
  --skip-triggers `
  --result-file="C:\Backups\ecommerce\ecommerce_routines_events.sql"
  
9-Compactar os backups
Compress-Archive -Path "C:\Backups\ecommerce\*.sql" `
                 -DestinationPath "C:\Backups\ecommerce\backup_ecommerce_$(Get-Date -Format 'yyyyMMdd_HHmmss').zip"

10-RECOVERY
Get-Content "C:\Backups\ecommerce\ecommerce_full_backup.sql" -Raw | mysql -u root -p

11- RECOVERY apenas da estrutura
cmd /c "mysql -u root -p < C:\Backups\ecommerce\ecommerce_schema_only.sql"

12- RECOVERY apenas dados
cmd /c "mysql -u root -p < C:\Backups\ecommerce\ecommerce_data_only.sql"

13-RECOVERY multiplos_bancos
cmd /c "mysql -u root -p < C:\Backups\ecommerce\multiplos_bancos_backup.sql"

14-Validar a mysql -u root -p -e "USE ecommerce; SHOW TABLES; SELECT COUNT(*) AS total_clientes FROM cliente; SELECT COUNT(*) AS total_pedidos FROM pedido;"

15- Verificar triggers
mysql -u root -p -e "USE ecommerce; SHOW TRIGGERS; SHOW EVENTS; SHOW PROCEDURE STATUS WHERE Db='ecommerce';"
